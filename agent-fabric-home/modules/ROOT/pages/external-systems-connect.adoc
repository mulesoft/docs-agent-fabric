= Work with Platform Agents and Tools
:keywords: external systems, slack integration, claude desktop, mcp, mulesoft enhanced experience, integrations
:page-aliases: general::exp-connect-with-external-systems.adoc

Connect to external systems so teams can act on governed services without leaving their preferred environment. You can integrate with collaboration tools like Slack or AI assistants like Claude Desktop.

The enhanced experience integrates with these external tools:

* xref:slack-integrate.adoc[]
+
Install the MuleSoft for Slack app to receive notifications, run shortcuts, and deep-link into the enhanced experience from your Slack workspace.

* xref:claude-desktop-connect.adoc[]
+
Connect Claude Desktop to the enhanced experience so developers can move between conversational AI workflows and governed catalogs.

* xref:teams-integrate.adoc[Integrate with Microsoft Copilot and Teams]

** Install the MuleSoft for Teams app to get alert notifications from the enhanced experience directly in Teams channels.

** Install the MuleSoft plugin in Microsoft Copilot to ask natural language questions and take action through Copilot Chat and Copilot Cowork. The plugin provides full capabilities of xref:mulesoft-mcp-server::reference-mcp-tools-platform.adoc[MuleSoft Platform MCP Server] tools.
