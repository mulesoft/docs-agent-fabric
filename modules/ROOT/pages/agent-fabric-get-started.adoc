= Get Started with Agent Fabric
:page-article-style: learning-map

MuleSoft Agent Fabric helps you turn your agent sprawl into a governed and highly coordinated, intelligent network. 

* It starts with discovery. Publish your agents in Exchange,  where every agent, no matter where it’s built, is cataloged and made easy to find, reuse, and compose into solutions.
* Next is orchestration. Connect and coordinate agents across ecosystems so that multi-step processes run smoothly, and agents can work together to deliver the right outcome.
* Then comes governance. Ensure every agent interaction is consistent, compliant, and secure..
* And finally, observing. Gain end-to-end visibility into how agents make decisions and perform, turning black-box AI into transparent, accountable systems.
