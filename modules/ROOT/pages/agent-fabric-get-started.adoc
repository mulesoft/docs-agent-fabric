[[discover-and-register-agents-and-tools]]
== Discover and Register Agents and Tools 

Use Anypoint Exchange to discover agentic assets (agents, brokers, MCP Servers, and so on). These assets are published and their metadata is managed in Anypoint Exchange.

[%header,cols="25a,25a,50a"]
|===
| Goal | Product | Key Steps

| Make agentic assets discoverable and reusable | Anypoint Exchange | Each asset in an agent network project is published with definitions (A2A cards) and stored in Exchange. The assets are searchable by tags, metadata, and names.
| Classify and describe assets | Anypoint Exchange | Assets are classified and described with tags, metadata, types,and names.
| Import Agentforce agents | Anypoint Exchange | Import Agentforce agents into Exchange automatically via synchronization in Exchange Settings.
|===

[[publish-and-deploy-the-broker]]
== Publish and Deploy the Broker 

After the broker is authored, publish the assets to Anypoint Exchange and then deploy the assets in Runtime Manager.

[%header,cols="25a,25a,50a"]
|===
| Goal | Product | Key Steps
| Publish the agent network project to Anypoint Exchange | Anypoint Exchange | Publish the agent network project to Anypoint Exchange as discoverable assets. After the agent domain assets are published to Exchange, the brokers defined in your YAML file are automatically published individually in Exchange as agent assets and tagged as `brokers`, making them discoverable and reusable across your organization.
| Deploy the broker in Runtime Manager | Runtime Manager | Set configuration variables and specify runtime details such as the environment and gateway targets.
|===
