= Set Up the Environment for Agent Fabric

== Before You Begin

To use Agent Fabric, make sure you have:

* A tenant relationship established with a trusted Salesforce organization.
* An Anypoint Platform (Titanium or Anypoint Integration Advanced package). You can use an existing account or create one from Anypoint Platform.
* An OpenAI instance and login credentials.
